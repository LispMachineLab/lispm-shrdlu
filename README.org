SHRDLU, which Terry Winograd wrote at MIT in 1968-1970, in any Emacs 30.1 or later, and an
application of [[https://github.com/LispMachineLab/lispm-desktop][LispM Desktop]], which its App Store installs and which dresses its windows from its
own side, with ~lispm-shrdlu-running-p~ and ~lispm-shrdlu-status~.  In code, the prefix is
~lispm-shrdlu-~.

* What it does

SHRDLU talks in English about a table of blocks, pyramids and a box, and moves them with a hand.
The dialogue is below a drawing of the table, where the hand goes up, across and down as SHRDLU
carries out a command, holding what it grasped:

#+begin_example
> pick up a big red block.
Ok.

> grasp the pyramid.
I don't know which pyramid you mean.

> find a block which is taller than the one you are holding and put it into the box.
Ok.

> what does the box contain?
The blue block and the blue pyramid.
#+end_example

The Sentences menu holds the lines of the dialogue Winograd published in 1972.  The code that
survives is incomplete: SHRDLU has forgotten some words of that dialogue, as =own= and =mine=,
and answers some questions as it did not then.

* For programs

~(lispm-shrdlu-ask SENTENCE CALLBACK)~ says ~SENTENCE~ to SHRDLU in the dialogue, starting it
first if need be, and calls ~CALLBACK~ with SHRDLU's answer once it waits for the next sentence;
sentences asked together are said one after the other, and after any the user sent.  If SHRDLU
stops, cannot start, the dialogue is closed or a new one begins first, ~CALLBACK~ gets nil and what
went wrong.  A sentence may hold no ~~~ or ~@~, which SHRDLU reads as commands of its own.  LispM Agent's skill for SHRDLU,
in the App Store's catalog, is made of it.

* How it works

This runs the Common Lisp port of the 1990s, revived by Tom Sgouros as [[https://github.com/tsgouros/www-shrdlu][www-shrdlu]], unchanged
but for fixes kept in [[https://github.com/LispMachineLab/www-shrdlu][LispMachineLab's fork]].  [[https://github.com/LispMachineLab/emacs-cl][Emacs Common Lisp]] runs it, in a batch Emacs
beside yours; the App Store installs it first, and [[https://github.com/LispMachineLab/lispm-kit][LispM Kit]], with which the window declares each
command once: its key, its menu item and, for the main ones, the words of a button.
[[file:lisp/shrdlu.lisp][lisp/shrdlu.lisp]] loads SHRDLU and makes its hand
report its moves, which lispm-shrdlu.el draws.

The first start fetches SHRDLU's Common Lisp with git, at the commit of
~lispm-shrdlu-source-revision~, into =~/.emacs.d/lispm-shrdlu/=.  ~M-x lispm-shrdlu~ opens the
dialogue, ~C-c C-n~ starts it again with the blocks where they began.
